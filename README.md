# ARTSTRONOMY 2026

An interactive arts and design final-year exhibition website.

Website: https://jonah0412.github.io/artstronomy-2026/

## Local preview

Run `node preview.mjs`, then open http://localhost:4173/artstronomy-2026/.

The `site/` folder contains the compiled website, including its artwork, 3D experiences, radio scanner, and living poster. This repository stores the compiled site rather than the original editable application source.

## Publishing

GitHub Pages publishes the `site/` folder through the included deployment workflow. In the repository's Pages settings, select **GitHub Actions** as the source.

Third-party library license notices are retained with their respective files. Exhibition artwork and creator content remain the property of their respective owners.
